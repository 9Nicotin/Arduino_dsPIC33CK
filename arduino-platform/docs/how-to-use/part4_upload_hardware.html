How To Use Arduino_dsPIC33CK

Part 4: Upload to Hardware

Installing? Use the Boards Manager — no scripts, no path editing.

In Arduino IDE open File → Preferences → Additional Boards Manager URLs and add:

https://github.com/9Nicotin/Arduino_dsPIC33CK/releases/latest/download/package_microchip_dspic33ck_index.json

Then Tools → Board → Boards Manager, search for dsPIC33CK, and click Install. You still need the XC-DSC compiler v4.00+, plus MPLAB X if you upload with a PICkit 4 / SNAP / nEDBG: their licences forbid redistribution, so they cannot ship inside the platform and are located automatically when a build or upload runs. The Device Family Packs are redistributable and are installed for you.

Anything below that uses install_arduino_ide.bat or platform.local.txt is the developer path — it installs an edited working copy of this repo. A normal install needs neither. Windows only.

4.1 Hardware Connections

1Connect PICkit 4 to the Board

Wire the 5-pin ICSP header between PICkit 4 and your dsPIC33CK board:


     PICkit 4                       dsPIC33CK32MP102
     (5-pin header)                 (28-pin chip)
    ┌──────────────┐               ┌──────────────────┐
    │ Pin 1: MCLR  │──────────────▶│ Pin 1:  MCLR     │
    │ Pin 2: VDD   │──────────────▶│ Pin 13: VDD      │
    │ Pin 3: GND   │──────────────▶│ Pin 8:  VSS/GND  │
    │ Pin 4: PGD   │──────────────▶│ PGD1 pin         │
    │ Pin 5: PGC   │──────────────▶│ PGC1 pin         │
    └──────────────┘               └──────────────────┘

    ▲ Pin 1 on PICkit 4 is marked with a triangle/arrow
Check VDD before connecting!
  • PICkit 4 can supply power (3.3V) if configured — or you use external power
  • NEVER set PICkit to supply 5V to dsPIC33CK!
  • If using external power, connect VDD/GND from your power supply too

2Connect PICkit 4 to PC

  1. Plug PICkit 4 into a USB port on your PC
  2. Wait for Windows to recognize it (driver installs automatically with MPLAB X)
  3. The PICkit 4 LED should be solid or blinking to indicate it's ready

3Add the Test LED

For the Blink example, connect an LED to RA0 (Arduino pin D0):


    dsPIC33CK Pin 2 (RA0)
         │
        [330Ω]   ← Current limiting resistor
         │
        [LED]    ← Anode (+, longer leg)
         │
        [LED]    ← Cathode (-, shorter leg / flat side)
         │
        GND      ← Pin 8 (VSS)

4.2 Upload from Arduino IDE

4Select Programmer in Arduino IDE

  1. Go to Tools → Programmer
  2. Select PICkit 4 (ICSP)

5Click Upload

  1. Click the Upload button (→ arrow) in the toolbar
  2. Or press Ctrl+U
  3. Arduino IDE will:
    • Compile the sketch (if not already compiled)
    • Call ipecmd.exe to program the device

4.3 Upload Errors and Solutions

Error MessageCauseSolution
ipecmd: not found MPLAB X not installed or wrong path Install MPLAB X — it is located automatically, newest version first. Only if it lives outside C:\Program Files\Microchip\, set build.tools.mplab.path in platform.local.txt. (tools.pickit4.path no longer exists.)
Target device not found PICkit not connected or bad wiring Check USB connection; verify all 5 ICSP wires; check pin orientation
Device ID does not match Wrong device selected Verify board is actually dsPIC33CK32MP102. Read chip markings.
Failed to program Device is code-protected Use MPLAB IPE to do a "Bulk Erase" first, then retry upload
VDD out of range Power supply issue Check VDD is 3.3V (2.7-3.6V range). Enable "Power from PICkit" if no external supply.
Unable to enter programming mode MCLR not connected properly Ensure MCLR pin has 10K pull-up to VDD and is connected to PICkit Pin 1

4.4 Alternative: UART Bootloader Upload

If you have a UART bootloader pre-programmed, you can upload via serial port:

Setup for UART Upload

  1. Select programmer: Tools → Programmer → UART Bootloader (Serial)
  2. Select port: Tools → Port → COMx (your USB-Serial adapter)
  3. Put device in bootloader mode (reset while holding BOOT pin)
  4. Click Upload (→)
Note: UART bootloader requires a bootloader to be pre-programmed using PICkit first. This is a one-time setup. After that, you can update via UART only.

4.5 Verifying Your Upload Worked

Check: Is the Program Running?

What to CheckExpected ResultIf Not Working
LED on D0 (Blink sketch) Blinks 1 second on / 1 second off Check LED polarity, resistor, wiring to pin 2
Serial output (Serial sketch) Text appears in terminal at correct baud Check TX/RX wiring, baud rate setting
Current consumption ~10-30mA at 3.3V (active) If 0mA: device not powered. If >100mA: short circuit!

4.6 Re-uploading New Code

To change your program:

  1. Edit your sketch in Arduino IDE
  2. Click Upload (→) again
  3. The previous program is erased and replaced with the new one
  4. Device resets and runs the new code immediately
You can upload as many times as you want. Flash memory supports approximately 10,000 erase/write cycles before wearing out.

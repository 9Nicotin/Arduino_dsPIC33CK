How To Use Arduino_dsPIC33CK

Part 2: Writing Sketches

2.1 Your First Sketch

1Create a New Sketch

  1. Open Arduino IDE
  2. Go to File → New Sketch
  3. Delete the default contents
  4. Type the following code:
/*
 * My First Arduino_dsPIC33CK Sketch
 * Blinks LED on pin D0 (RA0)
 */
#include "Arduino.h"

void setup()
{
    pinMode(LED_BUILTIN, OUTPUT);
}

void loop()
{
    digitalWrite(LED_BUILTIN, HIGH);
    delay(1000);
    digitalWrite(LED_BUILTIN, LOW);
    delay(1000);
}

2Save the Sketch

  1. Go to File → Save As
  2. Name it: Blink_dsPIC33CK
  3. Choose a location (e.g., Documents/Arduino/Blink_dsPIC33CK/)
  4. Click Save
Arduino saves it as Blink_dsPIC33CK.ino. The .ino extension is standard Arduino sketch format.

2.2 Sketch Structure Rules

Every Arduino_dsPIC33CK sketch must follow this template:

/* Required header - ALWAYS include this first */
#include "Arduino.h"

/* Optional: include if using Serial functions */
#include "HardwareSerial.h"

/* Global variables go here */
int myVariable = 0;

/* setup() - runs ONCE when device powers on */
void setup()
{
    /* Initialize pins, serial, etc. */
}

/* loop() - runs REPEATEDLY forever after setup() */
void loop()
{
    /* Your main program logic */
}
Three Mandatory Rules:
  1. Always include #include "Arduino.h" at the top
  2. Always define void setup() function
  3. Always define void loop() function

2.3 C vs C++ — Important Differences

XC-DSC v4.00+ compiles this core as C++, so Serial.println(), classes and templates all work. Two Arduino conveniences are still missing — there is no String class and no new/delete — so a few patterns must be written differently:

DO (C-style) ✓

// Variables at top of block
int i;
for (i = 0; i < 10; i++) {
    // ...
}

// C strings
const char *msg = "Hello";
Serial_print(msg);

// Function-style Serial
Serial_begin(9600);
Serial_println("text");
Serial_print_int(42, DEC);

// Fixed-size arrays
int values[10];

DON'T (C++ style) ✗

// Variable in for-loop (C99)
for (int i = 0; i < 10; i++) {
    // MAY cause warnings
}

// String class
String msg = "Hello";
Serial.print(msg);

// Object-style Serial
Serial.begin(9600);
Serial.println("text");
Serial.println(42);

// Dynamic allocation
int *values = new int[10];

2.5 Example Sketches

Example A: Digital Output (Blink Multiple LEDs)

#include "Arduino.h"

void setup()
{
    pinMode(0, OUTPUT);   // D0 = RA0 (LED 1)
    pinMode(1, OUTPUT);   // D1 = RA1 (LED 2)
    pinMode(2, OUTPUT);   // D2 = RA2 (LED 3)
}

void loop()
{
    /* Running light pattern */
    digitalWrite(0, HIGH);
    delay(200);
    digitalWrite(0, LOW);

    digitalWrite(1, HIGH);
    delay(200);
    digitalWrite(1, LOW);

    digitalWrite(2, HIGH);
    delay(200);
    digitalWrite(2, LOW);
}

Example B: Digital Input (Button with Debounce)

#include "Arduino.h"
#include "HardwareSerial.h"

#define BUTTON_PIN  2    /* D2 = RA2 */
#define LED_PIN     0    /* D0 = RA0 */

int ledState = LOW;
int lastButtonState = HIGH;
unsigned long lastDebounceTime = 0;
unsigned long debounceDelay = 50;

void setup()
{
    pinMode(LED_PIN, OUTPUT);
    pinMode(BUTTON_PIN, INPUT_PULLUP);
    Serial_begin(115200);
    Serial_println("Button debounce example ready");
}

void loop()
{
    int reading = digitalRead(BUTTON_PIN);

    if (reading != lastButtonState) {
        lastDebounceTime = millis();
    }

    if ((millis() - lastDebounceTime) > debounceDelay) {
        if (reading == LOW) {
            ledState = !ledState;
            digitalWrite(LED_PIN, ledState);
            Serial_print("LED toggled: ");
            Serial_println(ledState ? "ON" : "OFF");
            delay(200);  /* Prevent rapid toggling */
        }
    }
    lastButtonState = reading;
}

Example C: Analog Input + PWM Output

#include "Arduino.h"
#include "HardwareSerial.h"

void setup()
{
    Serial_begin(115200);
    Serial_println("Pot controls LED brightness");
    Serial_println("A0 (RB0) -> reads pot");
    Serial_println("D6 (RB1) -> PWM LED output");
}

void loop()
{
    /* Read potentiometer on A0 (D5/RB0) */
    int potValue = analogRead(A0);    /* 0-1023 */

    /* Map to PWM range */
    int brightness = map(potValue, 0, 1023, 0, 255);

    /* Output PWM on D6 (RB1, SCCP2) */
    analogWrite(6, brightness);

    /* Print every 500ms */
    static unsigned long lastPrint = 0;
    if (millis() - lastPrint > 500) {
        lastPrint = millis();
        Serial_print("Pot: ");
        Serial_print_int(potValue, DEC);
        Serial_print("  PWM: ");
        Serial_println_int(brightness, DEC);
    }
}

Example D: Serial Communication (Echo)

#include "Arduino.h"
#include "HardwareSerial.h"

void setup()
{
    pinMode(LED_BUILTIN, OUTPUT);
    Serial_begin(9600);
    Serial_println("=========================");
    Serial_println(" Arduino_dsPIC33CK Echo");
    Serial_println("=========================");
    Serial_println("Type something...");
}

void loop()
{
    if (Serial_available() > 0) {
        /* Blink LED on receive */
        digitalWrite(LED_BUILTIN, HIGH);

        /* Read and echo character */
        int c = Serial_read();
        Serial_print("You typed: ");
        Serial_write((uint8_t)c);
        Serial_print(" (ASCII: ");
        Serial_print_int(c, DEC);
        Serial_println(")");

        digitalWrite(LED_BUILTIN, LOW);
    }
}

Use these constants in your sketch:

A3  /* = pin 8,  RB3 */
A4  /* = pin 9,  RB4 */
A5  /* = pin 10, RB5 */

/* SPI */
MOSI /* = pin 11, RB6 */
MISO /* = pin 12, RB7 */

/* I2C */

HEX  /* = 16, hexadecimal */

OCT  /* = 8,  octal */

2.7 Common Mistakes to Avoid

Mistake #1: Forgetting #include "Arduino.h"
Without this, none of the Arduino functions (pinMode, digitalWrite, etc.) are defined.
Mistake #2: Writing Serial.begin() instead of Serial_begin()
The dot-syntax is C++ class method call. Use underscore function calls instead.
Mistake #3: Declaring variables inside for-loops
for (int i = 0; ...) may cause warnings. Prefer: int i; for (i = 0; ...)
Mistake #4: Writing your own main()
The Arduino core provides main(). Only write setup() and loop().
Mistake #5: Using 5V logic
dsPIC33CK is 3.3V ONLY. Never connect 5V signals directly. Use level shifters.

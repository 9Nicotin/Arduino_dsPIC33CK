Arduino_dsPIC33CK - Installation Guide

Complete setup guide: from a fresh Windows PC to blinking LEDs on your dsPIC33CK board

Quick Start (for experienced users)

If you already have Arduino IDE, XC-DSC compiler, and MPLAB X installed:

  1. Copy the arduino-platform folder to any location on your PC
  2. Double-click install_arduino_ide.bat
  3. Open Arduino IDE → Tools → Board → select your dsPIC33CK board
  4. Done! Write your sketch and click Upload

The installer auto-detects all tool paths. No manual configuration needed.

1. Prerequisites

Three software components must be installed before running the installer:

#SoftwareVersionPurposeDownload
1 Arduino IDE 2.x Development environment (editor + build system) arduino.cc/en/software
2 XC-DSC Compiler v3.31+ Compiles C code into dsPIC33CK machine code microchip.com/xc-dsc
3 MPLAB X IDE v6.20+ Provides ipecmd.exe (programmer) + Device Family Pack (DFP) microchip.com/mplab
Why MPLAB X? You don't need to use MPLAB X IDE itself. Arduino IDE uses only two things from it:
  • ipecmd.exe — command-line programmer for PICkit4 / SNAP / PKOB4
  • DFP (Device Family Pack) — device definitions, linker scripts, and register headers

2. Install Prerequisites

1Install Arduino IDE 2.x

  1. Download from arduino.cc/en/software
  2. Run installer with default settings
  3. Launch Arduino IDE once to create the data folders, then close it

This creates: %LOCALAPPDATA%\Arduino15\ (where our platform will be installed)

2Install XC-DSC Compiler

  1. Download from microchip.com/xc-dsc
  2. Run installer → Accept license → Install to default path
  3. When prompted "Add to PATH", select Yes

Default install location: C:\Program Files\Microchip\xc-dsc\v3.31\

3Install MPLAB X IDE + Device Family Pack

  1. Download from microchip.com/mplab
  2. Run installer with default settings
  3. Open MPLAB X IDE → Tools → Packs
  4. Install the DFP for your board:
Board / DeviceDFP to Install
dsPIC33CK32MP102 (Curiosity Nano)dsPIC33CK-MP_DFP
dsPIC33CK256MP508 (DM330030 Curiosity Dev Board)dsPIC33CK-MP_DFP
dsPIC33CK256MC002dsPIC33CK-MC_DFP

DFPs install to: %USERPROFILE%\.mchp_packs\Microchip\

Close MPLAB X IDE after installing the DFP.

3. Install Arduino_dsPIC33CK Platform

4Copy and Run the Installer

  1. Copy the arduino-platform folder to any location on your PC
    (USB drive, Desktop, Documents — anywhere is fine)
  2. Open the folder in Windows Explorer
  3. Double-click install_arduino_ide.bat
C:\Users\You\Desktop\arduino-platform> install_arduino_ide.bat

What the installer does:
  1. Copies platform files to %LOCALAPPDATA%\Arduino15\packages\microchip\hardware\dspic33ck\1.0.0\
  2. Auto-detects XC-DSC compiler path (newest version found)
  3. Auto-detects DFP paths for MP and MC device families
  4. Auto-detects MPLAB X IPE path (for device programming)
  5. Generates platform.local.txt with all detected paths
No manual path editing is needed if you installed everything to default locations.

6Configure Board Settings

After selecting a board, configure under Tools menu:

SettingOptionsRecommended
BoarddsPIC33CK32MP102 / dsPIC33CK256MP508 / dsPIC33CK256MC002Match your hardware
Clock Source8MHz Internal / External Crystal8MHz Internal (no crystal needed)
ProgrammerPKOB4 / PICkit 4 / PICkit 5 / SNAPMatch your debugger
Which programmer to select?
  • PKOB4 — DM330030 Curiosity Development Board (built-in programmer)
  • PICkit 4 / PICkit 5 — Standalone programmer connected via header
  • SNAP — MPLAB SNAP programmer

7Test Compile

Paste this minimal blink sketch and click Verify (checkmark button):

#include <Arduino.h>

void setup() {
    pinMode(LED_BUILTIN, OUTPUT);
}

void loop() {
    digitalWrite(LED_BUILTIN, HIGH);
    delay(500);
    digitalWrite(LED_BUILTIN, LOW);
    delay(500);
}

If compilation succeeds with no errors — your installation is complete!

6. Troubleshooting

ProblemCauseSolution
Board not visible in Arduino IDE IDE was open during install Close ALL Arduino IDE windows, reopen
Installer shows [WARNING] for XC-DSC Compiler not installed or non-default path Install XC-DSC from microchip.com/xc-dsc
Installer shows [WARNING] for DFP Device Family Pack not installed Open MPLAB X → Tools → Packs → Install dsPIC33CK-MP_DFP
Compile error: "unknown device" Wrong DFP or DFP path mismatch Re-run installer or check platform.local.txt
Upload fails: "Could not connect" Programmer not detected Check USB cable, driver, and programmer selection in Tools menu
Device doesn't run after upload Missing -OL flag or config issue Re-run installer (latest version has the fix)

Manual Path Override

Only needed if auto-detection fails. Edit this file:

%LOCALAPPDATA%\Arduino15\packages\microchip\hardware\dspic33ck\1.0.0\platform.local.txt

Contents:

# XC-DSC compiler bin/ directory (use forward slashes)
build.compiler.path=C:/Program Files/Microchip/xc-dsc/v3.31/bin/

# Device Family Pack path (MP family)
build.dfp.path=C:/Users/YOU/.mchp_packs/Microchip/dsPIC33CK-MP_DFP/1.15.423/xc16

# Device Family Pack path (MC family)
build.dfp.path.mc=C:/Users/YOU/.mchp_packs/Microchip/dsPIC33CK-MC_DFP/1.10.386/xc16

# MPLAB X IPE directory (for programming)
build.tools.mplab.path=C:/Program Files/Microchip/MPLABX/v6.30/mplab_platform/mplab_ipe

Restart Arduino IDE after saving changes.

7. What's in the arduino-platform Folder

arduino-platform/
├── install_arduino_ide.bat ← Run this to install
├── microchip/dspic33ck/
│   ├── platform.txt ← Build recipes (compiler, linker, bin2hex, upload)
│   ├── boards.txt ← Board definitions (MCU, clock, pins)
│   ├── cores/arduino/ ← Arduino API implementation (digitalWrite, delay, etc.)
│   ├── variants/ ← Pin mappings for each board
│   ├── tools/ ← Helper scripts (suppress-stderr, size wrapper)
│   └── programmers.txt ← Programmer definitions
└── docs/ ← Documentation (you are here)

Summary

To set up on a new computer:
  1. Install Arduino IDE 2.x, XC-DSC compiler, and MPLAB X IDE
  2. Install DFP via MPLAB X (Tools → Packs → dsPIC33CK-MP_DFP)
  3. Copy arduino-platform folder to any drive
  4. Run install_arduino_ide.bat
  5. Open Arduino IDE → select board → compile → upload

That's it! The installer handles all path configuration automatically.

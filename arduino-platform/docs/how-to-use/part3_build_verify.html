3.2 Build (Verify) Your Sketch

2Click Verify

Click the checkmark button (✓) in the top-left toolbar, or press Ctrl+R.

This compiles your sketch without uploading it — useful to check for errors first.

What Happens During Build

The Arduino IDE performs these steps automatically:


  Your Sketch (.ino)
       │
       ▼
  ┌──────────────────────────────────┐
  │ 1. Arduino IDE Preprocessor      │  Converts .ino → .cpp
  │    - Adds function prototypes    │  (adds forward declarations)
  │    - Wraps in extern "C"         │
  └──────────────────────────────────┘
       │
       ▼
  ┌──────────────────────────────────┐
  │ 2. XC-DSC Compiler (xc-dsc-gcc)  │  Compiles ALL files as C
  │    - Uses "-x c" flag            │  (forces C mode for .cpp)
  │    - -mcpu=(your device)         │
  │    - -mdfp=(DFP path)            │
  │    - Optimization: -O1           │
  └──────────────────────────────────┘
       │
       ▼
  ┌──────────────────────────────────┐
  │ 3. XC-DSC Archiver (xc-dsc-ar)   │  Packages core objects into core.a
  │    (via wrapper to suppress       │
  │     harmless stderr warnings)     │
  └──────────────────────────────────┘
       │
       ▼
  ┌──────────────────────────────────┐
  │ 4. XC-DSC Linker (xc-dsc-gcc)    │  Links all objects + core.a
  │    - Linker script: .gld (DFP)   │
  │    - --whole-archive core.a      │
  │    - Library: -lm                │
  └──────────────────────────────────┘
       │
       ▼
  ┌──────────────────────────────────┐
  │ 5. xc-dsc-bin2hex (via wrapper)   │  Creates .hex file for upload
  └──────────────────────────────────┘
       │
       ▼
  ┌──────────────────────────────────┐
  │ 6. Size report (via wrapper)      │  Uses xc-dsc-readelf to report
  │    - .text (flash usage)          │    memory usage
  │    - .data + .bss (RAM usage)     │
  └──────────────────────────────────┘

3.4 Build Errors and Solutions

Error Type 1: Compiler Not Found

fork/exec C:/Program Files/Microchip/xc-dsc/v3.31/bin/xc-dsc-gcc: no such file or directory
Error compiling for board Arduino_dsPIC33CK (dsPIC33CK32MP102).
Solution:
  1. Check if XC-DSC is installed: look for C:\Program Files\Microchip\xc-dsc\v3.31\bin\xc-dsc-gcc.exe
  2. If the path is different, edit platform.local.txt: 
    %LOCALAPPDATA%\Arduino15\packages\microchip\hardware\dspic33ck\1.0.0\platform.local.txt
  3. Change build.compiler.path= to your actual path
  4. Restart Arduino IDE

Error Type 2: Syntax Error (C++ in C code)

sketch.ino.cpp:15: error: expected ';' before ')' token
sketch.ino.cpp:20: error: 'class' undeclared
Error compiling for board Arduino_dsPIC33CK.
Solution: You're using C++ syntax. Common fixes:
ProblemFix
for (int i = 0; ...)int i; for (i = 0; ...)
Serial.begin(9600)Serial_begin(9600)
String s = "hi";const char *s = "hi";
new / deleteRemove or use malloc/free
class MyObj {...}Use struct + functions

Error Type 3: Undefined Function

undefined reference to `_setup'
undefined reference to `_loop'
Solution: Your sketch is missing setup() and/or loop(). Both functions must exist: 
void setup() { }   /* Even if empty, must be present */
void loop() { }    /* Even if empty, must be present */

Error Type 4: Multiple Definition of main

multiple definition of `_main'
Solution: You have a main() function in your sketch. Remove it — the Arduino core already provides main(). Only write setup() and loop().

Error Type 5: Program Too Large

section `.text' will not fit in region `program'
region `program' overflowed by 1234 bytes
Solution:
  • Your code exceeds 32KB flash. Reduce code size:
  • Remove unused functions or libraries
  • Use shorter strings in Serial_print()
  • Enable optimization: the platform defaults to -O1; for more, add compiler.c.extra_flags=-O2 to platform.local.txt

3.5 Build Output Files

After a successful build, Arduino IDE creates these files in a temporary folder:

FileDescriptionUsed For

sketch.ino.cpp.oCompiled object fileLinking
core.aArduino core library archiveLinking

To find the build folder: in Arduino IDE, enable File → Preferences → "Show verbose output during compilation". The full path to each file will be printed in the output.

3.6 Verbose Build Output

For troubleshooting, enable verbose compilation:

  1. Go to File → Preferences
  2. Check "Show verbose output during: compilation"
  3. Click OK
  4. Build again — you'll see every command that runs

This shows the exact xc-dsc-gcc command lines, which is helpful for diagnosing include path or flag issues.

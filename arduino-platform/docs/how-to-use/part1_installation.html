How To Use Arduino_dsPIC33CK

Part 1: Installation

This guide walks you through installing the Arduino_dsPIC33CK platform into your Arduino IDE so you can start writing and uploading sketches to the dsPIC33CK32MP102 microcontroller.

1.1 What You Need to Install

Three software components must be installed in order:

SoftwareVersionPurposeDownload
1. Arduino IDE2.xThe development environment (editor + build system)arduino.cc
2. XC-DSC Compilerv3.31+Compiles C code into dsPIC33CK machine codemicrochip.com
3. MPLAB X IDEv6.20+Provides ipecmd.exe for PICkit4 upload + DFP packsmicrochip.com

1.2 Install Arduino IDE

1Download Arduino IDE 2.x

  1. Go to https://www.arduino.cc/en/software
  2. Download Arduino IDE 2.x for Windows
  3. Run the installer with default settings
  4. Launch Arduino IDE once to create the data folders
After first launch, Arduino creates: %LOCALAPPDATA%\Arduino15\
This is where our platform will be installed.

1.3 Install XC-DSC Compiler

2Download and Install XC-DSC

  1. Go to https://www.microchip.com/xc-dsc
  2. Download MPLAB XC-DSC Compiler v3.31
  3. Run installer → Accept license → Install to default path: 
    C:\Program Files\Microchip\xc-dsc\v3.31\
  4. When prompted "Add to PATH", select YES
Note: XC-DSC is Microchip's compiler for dsPIC DSC devices. It is C-only (no C++ support), which is why the Arduino platform compiles all files as C.

3Verify XC-DSC Installation

Open Command Prompt (Win+R → type cmd → Enter) and run:

C:\Users\YourName> xc-dsc-gcc --version
Microchip XC-DSC Compiler v3.31
Copyright (C) Microchip Technology Inc.

✓ If you see version info, XC-DSC is correctly installed.

If you get "not recognized", add XC-DSC to PATH manually:

  1. Press Win+S, search "Environment Variables"
  2. Click "Edit the system environment variables"
  3. Click "Environment Variables" button
  4. Under "System variables", find Path, click Edit
  5. Click "New" and add: C:\Program Files\Microchip\xc-dsc\v3.31\bin
  6. Click OK on all dialogs
  7. Reopen Command Prompt and retry

1.4 Install MPLAB X IDE (for ipecmd + Device Family Pack)

4Download and Install MPLAB X

  1. Go to https://www.microchip.com/mplab
  2. Download MPLAB X IDE v6.20+
  3. Run installer with default settings
  4. This installs ipecmd.exe which Arduino IDE uses to program via PICkit 4
You don't need to use MPLAB X IDE itself — we only need its ipecmd.exe tool for uploading and its DFP (Device Family Pack) for device definitions. You'll write and compile everything in Arduino IDE.

4bInstall the Device Family Pack (DFP)

The XC-DSC compiler needs a DFP to recognize the target device. Open MPLAB X IDE once to install it:

  1. Open MPLAB X IDE
  2. Go to Tools → Packs (or Pack Manager)
  3. Search for and install the DFP for your board:
    BoardDFP to Install
    dsPIC33CK32MP102dsPIC33CK-MP_DFP (latest version)
    dsPIC33CK256MC002dsPIC33CK-MC_DFP (latest version)
  4. Close MPLAB X IDE

DFPs install to:

%USERPROFILE%\.mchp_packs\Microchip\dsPIC33CK-MP_DFP\
%USERPROFILE%\.mchp_packs\Microchip\dsPIC33CK-MC_DFP\
Important: Without the DFP, the compiler will fail with "unknown device" errors. The installer auto-detects the DFP location — no manual path editing needed.

1.5 Install Arduino_dsPIC33CK Platform

5Run the Installation Script

  1. Open Windows Explorer
  2. Navigate to the arduino-platform folder you received
  3. Double-click install_arduino_ide.bat
  4. Wait for completion — the script auto-detects all tool paths
C:\...arduino-platform> install_arduino_ide.bat

The installer auto-detects your XC-DSC compiler, DFP packs, and MPLAB X installation. No manual path editing is needed if you installed everything to default locations.

6Verify Platform is Detected

  1. Open Arduino IDE
  2. Go to Tools → Board
  3. Look for the dsPIC33CK boards:
Tools → Board:
┌────────────────────────────────────────────────────┐
│ Arduino AVR Boards │
│   Arduino Uno │
│   Arduino Mega │
│ Arduino_dsPIC33CK (dsPIC33CK32MP102) ← 32KB MP │
│ Arduino_dsPIC33CK (dsPIC33CK256MC002) ← 256KB MC │
└────────────────────────────────────────────────────┘
Don't see it? Close ALL Arduino IDE windows completely, then reopen. The IDE only scans for new boards on startup.

7Manual Path Override (only if auto-detect fails)

The installer auto-detects paths. Only edit manually if you see [WARNING] messages during install:

  1. Open this file in a text editor:
    %LOCALAPPDATA%\Arduino15\packages\microchip\hardware\dspic33ck\1.0.0\platform.local.txt
  2. Edit the paths to match your installation: 
    # XC-DSC compiler bin/ directory
build.compiler.path=C:/Program Files/Microchip/xc-dsc/v3.31/bin/

# DFP paths (MP and MC families)
build.dfp.path=C:/Users/YOU/.mchp_packs/Microchip/dsPIC33CK-MP_DFP/1.15.423/xc16
build.dfp.path.mc=C:/Users/YOU/.mchp_packs/Microchip/dsPIC33CK-MC_DFP/1.10.386/xc16

# MPLAB X IPE (for PICkit 4/SNAP upload)
build.tools.mplab.path=C:/Program Files/Microchip/MPLABX/v6.30/mplab_platform/mplab_ipe
  3. Save the file and restart Arduino IDE

1.6 Installation Verification Checklist

  • Arduino IDE 2.x opens without errors
  • xc-dsc-gcc --version works in Command Prompt
  • MPLAB X is installed (ipecmd.exe exists)
  • DFP installed (at least one): dsPIC33CK-MP_DFP and/or dsPIC33CK-MC_DFP
  • install_arduino_ide.bat completed — all paths auto-detected
  • "Arduino_dsPIC33CK" boards appear in Tools → Board menu
Installation complete! Continue to Part 2: Writing Sketches to learn how to write code for the dsPIC33CK in Arduino IDE.

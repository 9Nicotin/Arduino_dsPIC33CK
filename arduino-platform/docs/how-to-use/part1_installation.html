How To Use Arduino_dsPIC33CK

Part 1: Installation

Installing? Use the Boards Manager — no scripts, no path editing.

In Arduino IDE open File → Preferences → Additional Boards Manager URLs and add:

https://github.com/9Nicotin/Arduino_dsPIC33CK/releases/latest/download/package_microchip_dspic33ck_index.json

Then Tools → Board → Boards Manager, search for dsPIC33CK, and click Install. You still need the XC-DSC compiler v4.00+, plus MPLAB X if you upload with a PICkit 4 / SNAP / nEDBG: their licences forbid redistribution, so they cannot ship inside the platform and are located automatically when a build or upload runs. The Device Family Packs are redistributable and are installed for you.

Anything below that uses install_arduino_ide.bat or platform.local.txt is the developer path — it installs an edited working copy of this repo. A normal install needs neither. Windows only.

This guide walks you through installing the Arduino_dsPIC33CK platform into your Arduino IDE so you can start writing and uploading sketches to the dsPIC33CK32MP102 microcontroller.

1.1 What You Need to Install

Three software components must be installed in order:

SoftwareVersionPurposeDownload
1. Arduino IDE2.xThe development environment (editor + build system)arduino.cc
2. XC-DSC Compilerv4.00+Compiles your sketch. v4.00 is the first release with C++ (xc-dsc-g++), which this core requires.microchip.com
3. MPLAB X IDEv6.20+ (optional)Provides ipecmd.exe for PICkit 4 / PICkit 5 / SNAP / PKOB4 / nEDBG upload. The Device Family Packs no longer come from here — the Boards Manager installs them.microchip.com

1.2 Install Arduino IDE

1Download Arduino IDE 2.x

  1. Go to https://www.arduino.cc/en/software
  2. Download Arduino IDE 2.x for Windows
  3. Run the installer with default settings
  4. Launch Arduino IDE once to create the data folders
After first launch, Arduino creates: %LOCALAPPDATA%\Arduino15\
This is where our platform will be installed.

1.3 Install XC-DSC Compiler

2Download and Install XC-DSC

  1. Go to https://www.microchip.com/xc-dsc
  2. Download MPLAB XC-DSC Compiler v4.00 or newer
  3. Run installer → Accept license → Install to default path: 
    C:\Program Files\Microchip\xc-dsc\v4.00\
  4. The "Add to PATH" prompt does not matter — this platform calls the compiler by full path. Any v* directory under C:\Program Files\Microchip\xc-dsc\ is found automatically, newest first.
Note: XC-DSC is Microchip's compiler for dsPIC DSC devices. Version 4.00 added C++ (xc-dsc-g++), and this platform compiles everything as C++ — which is why v4.00 is the minimum. Earlier versions are C-only and will not build this core.

3Verify XC-DSC Installation

Open Command Prompt (Win+R → type cmd → Enter) and run it by full path — XC-DSC does not need to be on PATH for Arduino builds, so testing the bare name proves nothing either way:

C:\Users\YourName> "C:\Program Files\Microchip\xc-dsc\v4.00\bin\xc-dsc-gcc.exe" --version
xc-dsc-gcc (Microchip XC-DSC v4.00) ...
Copyright (C) Microchip Technology Inc.

✓ A version of 4.00 or higher means you are ready.

Also confirm the C++ driver is present, since the core is C++ throughout:

C:\Users\YourName> dir "C:\Program Files\Microchip\xc-dsc\v4.00\bin\xc-dsc-g++.exe"
✓ If this file exists, this XC-DSC can build the platform.

If neither path exists, adjust the version number to whatever you installed. If XC-DSC lives outside C:\Program Files\Microchip\, see Manual Path Override below.

1.4 Install MPLAB X IDE (for ipecmd — only if you upload with a debugger)

4Download and Install MPLAB X

  1. Go to https://www.microchip.com/mplab
  2. Download MPLAB X IDE v6.20+
  3. Run installer with default settings
  4. This installs ipecmd.exe, which Arduino IDE uses to program via PICkit 4 / PICkit 5 / SNAP / PKOB4 / nEDBG
  5. Any v* directory under C:\Program Files\Microchip\MPLABX\ is found automatically, newest first
You never open MPLAB X IDE itself — the only file used from it is ipecmd.exe. You write and compile everything in Arduino IDE.

Skip this step entirely if you only compile, or if you upload over a UART bootloader. The Device Family Packs no longer come from here either — see the next step.

4bDevice Family Packs — nothing to do

The compiler does need a DFP to recognize the target device, but you no longer install one. Both packs are Apache-2.0 licensed, so the Boards Manager ships them with the platform, pruned to the four supported devices:

%LOCALAPPDATA%\Arduino15\packages\microchip\tools\dsPIC33CK-MP_DFP\
%LOCALAPPDATA%\Arduino15\packages\microchip\tools\dsPIC33CK-MC_DFP\
Earlier versions of this guide had you install these through Tools → Packs in MPLAB X. Packs already sitting in %USERPROFILE%\.mchp_packs\ are simply ignored by Arduino builds, and you should not point build.dfp.path at them — that shadows the packs the platform installed and goes stale on the next update.

1.5 Install Arduino_dsPIC33CK Platform

5Install the Platform from the Boards Manager

  1. Open Arduino IDE → File → Preferences → Additional Boards Manager URLs and add: 
    https://github.com/9Nicotin/Arduino_dsPIC33CK/releases/latest/download/package_microchip_dspic33ck_index.json
  2. Click OK, then open Tools → Board → Boards Manager.
  3. Search for dsPIC33CK and click Install (under 1.5 MB: the platform plus both pruned Device Family Packs).
Nothing to configure afterwards. The XC-DSC compiler and MPLAB X are located at the moment a build or upload runs, newest version first, so no file needs your paths written into it — and no platform.local.txt is created.
Editing the platform itself? The Boards Manager can only install released archives, never your working tree. Clone the repo and run arduino-platform\install_arduino_ide.bat, which copies your tree over the installed platform and reports the tools a build would use. Re-run it after every source change — the IDE compiles what is in %LOCALAPPDATA%\Arduino15, not what is in your clone. Its output looks like this:

7Manual Path Override (only if a tool is installed elsewhere)

Needed only if XC-DSC or MPLAB X is installed outside C:\Program Files\Microchip\. A Boards Manager install creates no platform.local.txt; you create one:

  1. Create this file in a text editor:
    %LOCALAPPDATA%\Arduino15\packages\microchip\hardware\dspic33ck\1.0.0\platform.local.txt
  2. Set only the keys you need — forward slashes, trailing slash on the compiler path: 
    # XC-DSC compiler bin/ directory
build.compiler.path=D:/tools/xc-dsc/v4.00/bin/

# MPLAB X IPE (for PICkit 4 / PICkit 5 / SNAP / PKOB4 / nEDBG upload)
build.tools.mplab.path=D:/tools/MPLABX/v6.35/mplab_platform/mplab_ipe
    The environment variables XCDSC_PATH and MPLABX_IPE_PATH do the same job without editing any file.
  3. Save the file and restart Arduino IDE
Do not add build.dfp.path or build.dfp.path.mc here. Those point at the Device Family Packs the Boards Manager installed; an override shadows them and goes stale on the next platform update.

1.6 Installation Verification Checklist

  • Arduino IDE 2.x opens without errors
  • "C:\Program Files\Microchip\xc-dsc\v4.00\bin\xc-dsc-gcc.exe" --version reports v4.00 or newer
  • xc-dsc-g++.exe exists in that same bin directory
  • MPLAB X is installed (ipecmd.exe exists) — only if you upload with a debugger
  • Boards Manager URL added, and dsPIC33CK shows as Installed
  • "Arduino_dsPIC33CK" boards appear in Tools → Board menu
Installation complete! Continue to Part 2: Writing Sketches to learn how to write code for the dsPIC33CK in Arduino IDE.

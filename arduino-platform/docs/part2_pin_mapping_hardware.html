Two devices, two tables. Sections 2.1–2.2 cover dsPIC33CK256MC005 (Curiosity Nano, 48-pin, D0–D38). Sections 2.3 onward cover dsPIC33CK32MP102 (28-pin, D0–D20). The two pin maps are unrelated — the same Arduino number is a different port on each. Check which board is selected in Tools > Board before reading a row.

2.1 dsPIC33CK256MC005 (Curiosity Nano) Pin Map

The dsPIC33CK256MC005 is a 48-pin device with 39 bonded I/O pins, numbered D0–D38. It is the priority device for this platform and the one the bootloader in Part 6 is built for.

A drawn pin-map diagram is in the repository: docs/img/pinmap-dspic33ck256mc005.svg, also shown on the front page of the repository. It is drawn by a generator whose pad tables are checked against variant.c and pins_arduino.h on every pin, so a pad that disagrees with what the core compiles is a build failure rather than a wrong picture. The table below is generated from the same two files.
Physical package pin numbers are deliberately not given for this device. Identify a pin the two ways that are verifiable from this platform: the port name the Curiosity Nano silkscreens on its edge pads (RC10, RD13, …), and the Arduino number your sketch passes to digitalWrite(). If you are wiring a bare dsPIC33CK on your own board, take the package pin numbers from the data sheet for your package.

2.2 dsPIC33CK256MC005 Complete Pin Mapping Table

All 39 pins. The An names are sequential Arduino analog numbers and do not match the chip's ANx channel numbers — for example A19 is D37, which reads ADC channel AN18. Pass the An name (or its Dn number) to analogRead(); the ANx number in the Functions column is only for cross-referencing the data sheet.

D10 (RB5) and D11 (RB6) are the debugger's programming lines (PGD3/PGC3) on the Curiosity Nano. Driving them from a sketch fights the on-board nEDBG and can cost you the ability to program the board until you power-cycle it. They are in the pin map for completeness; treat them as unavailable.
MCPWM pins have no Arduino API on MC parts. D15– D20 and D35 are wired to the motor-control PWM peripheral. HRPWM.h is a hard error on MC devices, so these are usable as plain digital I/O only. analogWrite() works on D5–D8, which are the SCCP timers.

2.5 Hardware Wiring for Testing

Blink Test Wiring (Simplest)


    dsPIC33CK32MP102
    +--------+
    |        |
    |  RA0 --+--[330 ohm]--[LED]--GND
    | (pin 2)|
    |        |
    |  VDD --+-- 3.3V
    | (pin13)|
    |        |
    |  VSS --+-- GND
    | (pin 8)|
    |        |
    | MCLR --+-- 3.3V (via 10K resistor)
    | (pin 1)|
    +--------+

    PICkit 4 Connection:
    Pin 1: MCLR
    Pin 2: VDD (3.3V)
    Pin 3: GND
    Pin 4: PGD1
    Pin 5: PGC1

Serial (UART) Test Wiring


    dsPIC33CK32MP102              USB-Serial Adapter
    +--------+                    +----------+
    |        |                    |          |
    |  RB5 --+--------------------+-- RX     |
    | (D10)  |  (UART TX)        |          |
    |        |                    |          |
    |  RB4 --+--------------------+-- TX     |
    | (D9)   |  (UART RX)        |          |
    |        |                    |          |
    |  GND --+--------------------+-- GND    |
    |        |                    |          |
    +--------+                    +----------+
                                       |
                                    [USB to PC]
                                       |
                                  Serial Monitor
                                  (9600 baud)

    IMPORTANT: Cross TX/RX!
    - dsPIC TX (RB5) goes to adapter RX
    - dsPIC RX (RB4) goes to adapter TX
    - Connect GND together
    - Adapter must be 3.3V logic!

Analog Read Test Wiring


         3.3V
          |
         [R] <-- Potentiometer (10K)
          |
          +---------- RB0 (D5 / A0, pin 4)
          |
         [R]
          |
         GND

    Turn the potentiometer to vary voltage from 0V to 3.3V.
    analogRead(A0) returns 0-1023.

PWM (LED Brightness) Test Wiring


    dsPIC33CK32MP102
    +--------+
    |        |
    |  RB0 --+--[330 ohm]--[LED]--GND
    | (D5)   |
    |        |    (PWM output - LED brightness varies)
    +--------+

    analogWrite(5, 128);  // 50% brightness

2.6 Power Supply Requirements

Parameter Min Typical Max
VDD (supply voltage) 2.7V 3.3V 3.6V
I/O pin output current - - 25 mA per pin
Total device current - ~30 mA 200 mA
Analog input voltage 0V (VSS) - 3.3V (VDD)
Decoupling Capacitors: Place 100nF ceramic capacitors as close as possible to each VDD/VSS pair. Place a 10uF capacitor on VCAP (pin 15).

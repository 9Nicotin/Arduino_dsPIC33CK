2.1 dsPIC33CK32MP102 Pinout Diagram

The dsPIC33CK32MP102 is a 28-pin device. Here's how the physical pins map to Arduino pin numbers:


         dsPIC33CK32MP102 (28-pin SPDIP/SOIC)
        +----------------------------+
        |                            |
  MCLR -| 1                      28 |- AVDD
   RA0 -| 2   (D0, LED_BUILTIN)  27 |- AVSS
   RA1 -| 3   (D1)               26 |- RB15 (D20)
   RB0 -| 4   (D5, A0, PWM)      25 |- RB14 (D19)
   RB1 -| 5   (D6, A1, PWM)      24 |- RB13 (D18)
   RB2 -| 6   (D7, A2, PWM)      23 |- RB12 (D17)
   RB3 -| 7   (D8, A3, PWM)      22 |- RB11 (D16, SS)
   VSS -| 8                       21 |- RB10 (D15, SCL)
   RA2 -| 9   (D2)               20 |- VDD
   RA3 -| 10  (D3)               19 |- RB9  (D14, SDA)
   RB4 -| 11  (D9, A4, RX)       18 |- RB8  (D13, SCK)
   RA4 -| 12  (D4)               17 |- RB7  (D12, MISO)
   VDD -| 13                      16 |- RB6  (D11, MOSI)
   RB5 -| 14  (D10, A5, TX)      15 |- RB5  (VCAP)
        |                            |
        +----------------------------+

2.3 Hardware Wiring for Testing

Blink Test Wiring (Simplest)


    dsPIC33CK32MP102
    +--------+
    |        |
    |  RA0 --+--[330 ohm]--[LED]--GND
    | (pin 2)|
    |        |
    |  VDD --+-- 3.3V
    | (pin13)|
    |        |
    |  VSS --+-- GND
    | (pin 8)|
    |        |
    | MCLR --+-- 3.3V (via 10K resistor)
    | (pin 1)|
    +--------+

    PICkit 4 Connection:
    Pin 1: MCLR
    Pin 2: VDD (3.3V)
    Pin 3: GND
    Pin 4: PGD1
    Pin 5: PGC1

Serial (UART) Test Wiring


    dsPIC33CK32MP102              USB-Serial Adapter
    +--------+                    +----------+
    |        |                    |          |
    |  RB5 --+--------------------+-- RX     |
    | (D10)  |  (UART TX)        |          |
    |        |                    |          |
    |  RB4 --+--------------------+-- TX     |
    | (D9)   |  (UART RX)        |          |
    |        |                    |          |
    |  GND --+--------------------+-- GND    |
    |        |                    |          |
    +--------+                    +----------+
                                       |
                                    [USB to PC]
                                       |
                                  Serial Monitor
                                  (9600 baud)

    IMPORTANT: Cross TX/RX!
    - dsPIC TX (RB5) goes to adapter RX
    - dsPIC RX (RB4) goes to adapter TX
    - Connect GND together
    - Adapter must be 3.3V logic!

Analog Read Test Wiring


         3.3V
          |
         [R] <-- Potentiometer (10K)
          |
          +---------- RB0 (D5 / A0, pin 4)
          |
         [R]
          |
         GND

    Turn the potentiometer to vary voltage from 0V to 3.3V.
    analogRead(A0) returns 0-1023.

PWM (LED Brightness) Test Wiring


    dsPIC33CK32MP102
    +--------+
    |        |
    |  RB0 --+--[330 ohm]--[LED]--GND
    | (D5)   |
    |        |    (PWM output - LED brightness varies)
    +--------+

    analogWrite(5, 128);  // 50% brightness

2.4 Power Supply Requirements

Parameter Min Typical Max
VDD (supply voltage) 2.7V 3.3V 3.6V
I/O pin output current - - 25 mA per pin
Total device current - ~30 mA 200 mA
Analog input voltage 0V (VSS) - 3.3V (VDD)
Decoupling Capacitors: Place 100nF ceramic capacitors as close as possible to each VDD/VSS pair. Place a 10uF capacitor on VCAP (pin 15).

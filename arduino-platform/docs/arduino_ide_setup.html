Arduino_dsPIC33CK

Arduino IDE Setup & Usage Guide

Installing? Use the Boards Manager — no scripts, no path editing.

In Arduino IDE open File → Preferences → Additional Boards Manager URLs and add:

https://github.com/9Nicotin/Arduino_dsPIC33CK/releases/latest/download/package_microchip_dspic33ck_index.json

Then Tools → Board → Boards Manager, search for dsPIC33CK, and click Install. You still need the XC-DSC compiler v4.00+, plus MPLAB X if you upload with a PICkit 4 / SNAP / nEDBG: their licences forbid redistribution, so they cannot ship inside the platform and are located automatically when a build or upload runs. The Device Family Packs are redistributable and are installed for you.

Anything below that uses install_arduino_ide.bat or platform.local.txt is the developer path — it installs an edited working copy of this repo. A normal install needs neither. Windows only.

Prerequisites before starting:
  • Arduino IDE 2.x installed (download here)
  • Microchip XC-DSC compiler v4.00+ installed (download here)
  • MPLAB X IDE installed (for PICkit4/SNAP upload via ipecmd)

Step 1: Install the Platform

1Add the Boards Manager URL

  1. Open Arduino IDE 2.x
  2. Go to File → Preferences
  3. In Additional Boards Manager URLs, paste: 
    https://github.com/9Nicotin/Arduino_dsPIC33CK/releases/latest/download/package_microchip_dspic33ck_index.json
  4. Click OK

2Install from the Boards Manager

  1. Go to Tools → Board → Boards Manager
  2. Search for dsPIC33CK
  3. Click Install

What this does: downloads the platform and the two pruned Device Family Packs into:
%LOCALAPPDATA%\Arduino15\packages\microchip\

No path configuration. There is no platform.local.txt to edit. The XC-DSC compiler and MPLAB X are located automatically when a build or upload runs — including choosing the newest of several installed versions — and the Device Family Packs come from the Boards Manager itself.

3Check the Prerequisites

Two Microchip tools stay user-installed, because their licences are non-transferable and forbid redistribution:

ToolNeeded forNotes
XC-DSC v4.00+ compiling v4.00 is the first with C++ (xc-dsc-g++), which this core requires. The free edition is enough. It does not need to be on PATH.
MPLAB X IDE upload via PICkit 4 / SNAP / nEDBG Not needed to compile, or to upload over the UART bootloader.

Installed somewhere other than C:\Program Files\Microchip\? Then — and only then — create a platform.local.txt next to the installed platform.txt with build.compiler.path= and/or build.tools.mplab.path=.

Developing this platform? The Boards Manager can only install released archives, never your working tree, so contributors run arduino-platform\install_arduino_ide.bat from a clone instead. It copies the edited tree over the installed platform and re-checks the prerequisites; re-run it after every source change. Everyone else can ignore it.

Step 3: Write Your First Sketch

6Create a New Sketch

Go to File → New Sketch. Replace the contents with:

/*
 * Blink - Arduino_dsPIC33CK
 * LED on pin D0 (RA0) blinks every 1 second.
 *
 * NOTE: XC-DSC v4.00+ compiles this core as C++, so ordinary Arduino syntax works:
 *   - Serial.begin() / Serial.print() (Serial_begin() still works from .c files)
 *   - Classes, templates and overloading are available
 *   - But there is no String class and no new/delete
 */
#include "Arduino.h"

void setup()
{
    pinMode(LED_BUILTIN, OUTPUT);
}

void loop()
{
    digitalWrite(LED_BUILTIN, HIGH);
    delay(1000);
    digitalWrite(LED_BUILTIN, LOW);
    delay(1000);
}

Save it as Blink_dsPIC33CK (File → Save As)

Critical Rules When Writing Sketches:
  1. Always include #include "Arduino.h" at the top
  2. For Serial, add #include "HardwareSerial.h" and use Serial_begin() not Serial.begin()
  3. No C++ features: no classes, no String, no new/delete, no templates
  4. Declare all variables at the TOP of a block (C89-style)
  5. Do NOT write your own main() — only setup() and loop()

Step 4: Build (Verify)

7Click Verify (Compile)

  1. Click the checkmark button (✓) in the toolbar, or press Ctrl+R
  2. Watch the Output panel at the bottom

Step 5: Upload to Hardware

8Connect PICkit 4 and Upload

  1. Connect PICkit 4 to the board's ICSP header
  2. Connect PICkit 4 to PC via USB
  3. Click the Upload button (→ arrow) or press Ctrl+U
  4. Arduino IDE calls ipecmd to program the device
Uploading... "C:/Program Files/Microchip/MPLABX/v6.20/mplab_platform/bin/ipecmd.exe" -TPPK4 -PdsPIC33CK32MP102 -M -F"sketch.hex" Connecting to PICkit 4... Device ID verified: dsPIC33CK32MP102 Erasing... Programming... Verify... Done. Upload complete.

Step 6: Using Serial Monitor

9Open Serial Monitor for UART Output

If your sketch uses Serial, connect a USB-UART adapter and:

  1. Select the correct COM port: Tools → Port → COMx
  2. Open Serial Monitor: Tools → Serial Monitor or Ctrl+Shift+M
  3. Set baud rate to match your code (e.g., 115200)
/* Example sketch with Serial */
#include "Arduino.h"
#include "HardwareSerial.h"

void setup()
{
    pinMode(LED_BUILTIN, OUTPUT);
    Serial_begin(115200);
    Serial_println("Hello from Arduino_dsPIC33CK!");
}

void loop()
{
    int adc = analogRead(A0);
    Serial_print("ADC: ");
    Serial_println_int(adc, DEC);
    delay(500);
}
Note: The Serial Monitor COM port is for your USB-UART adapter (connected to RB4/RB5), NOT the PICkit 4. You may need to select a different port for monitoring vs. programming.

Troubleshooting Arduino IDE Issues

ProblemSolution
Board not visible in Tools menu Re-install from Tools → Board → Boards Manager, then restart Arduino IDE completely (close all windows). Developer installs: re-run install_arduino_ide.bat.
"XC-DSC compiler not found" Install XC-DSC v4.00+. It is found automatically and does not need to be on PATH. Only if it lives outside C:\Program Files\Microchip\, set build.compiler.path in platform.local.txt.
C++ features rejected, or xc-dsc-g++.exe missing Your XC-DSC predates v4.00. C++ (classes, templates, overloading) is supported from v4.00 on, and this core requires it — upgrade the compiler. There is still no String class and no new/delete.
"undefined reference to _setup" Your sketch must have void setup() and void loop() functions.
Upload fails: "ipecmd not found" Install MPLAB X. It is located automatically, including picking the newest of several installed versions. Only if it lives outside C:\Program Files\Microchip\, set build.tools.mplab.path in platform.local.txt.
Upload fails: "Target not found" Check PICkit4 connection. Ensure MCLR, VDD, GND, PGD, PGC wired correctly.
"variable declared in for loop" error Declare loop variable before the for: int i; for(i=0;...) instead of for(int i=0;...)
Tip: If you get stuck, you can always fall back to MPLAB X IDE which has full native support for XC16 and dsPIC33CK. The Arduino IDE integration is a convenience layer — MPLAB X gives you the debugger, breakpoints, and register views.

Step 3: Write Your First Sketch

6Create a New Sketch

Go to File → New Sketch. Replace the contents with:

/*
 * Blink - Arduino_dsPIC33CK
 * LED on pin D0 (RA0) blinks every 1 second.
 *
 * IMPORTANT: Since XC16 is C-only, use C-style syntax:
 *   - Use Serial_begin() not Serial.begin()
 *   - Use Serial_print() not Serial.print()
 *   - No String class, no new/delete
 */
#include "Arduino.h"

void setup()
{
    pinMode(LED_BUILTIN, OUTPUT);
}

void loop()
{
    digitalWrite(LED_BUILTIN, HIGH);
    delay(1000);
    digitalWrite(LED_BUILTIN, LOW);
    delay(1000);
}

Save it as Blink_dsPIC33CK (File → Save As)

Critical Rules When Writing Sketches:
  1. Always include #include "Arduino.h" at the top
  2. For Serial, add #include "HardwareSerial.h" and use Serial_begin() not Serial.begin()
  3. No C++ features: no classes, no String, no new/delete, no templates
  4. Declare all variables at the TOP of a block (C89-style)
  5. Do NOT write your own main() — only setup() and loop()

Step 5: Upload to Hardware

8Connect PICkit 4 and Upload

  1. Connect PICkit 4 to the board's ICSP header
  2. Connect PICkit 4 to PC via USB
  3. Click the Upload button (→ arrow) or press Ctrl+U
  4. Arduino IDE calls ipecmd to program the device
Uploading... "C:/Program Files/Microchip/MPLABX/v6.20/mplab_platform/bin/ipecmd.exe" -TPPK4 -PdsPIC33CK32MP102 -M -F"sketch.hex" Connecting to PICkit 4... Device ID verified: dsPIC33CK32MP102 Erasing... Programming... Verify... Done. Upload complete.

Step 6: Using Serial Monitor

9Open Serial Monitor for UART Output

If your sketch uses Serial, connect a USB-UART adapter and:

  1. Select the correct COM port: Tools → Port → COMx
  2. Open Serial Monitor: Tools → Serial Monitor or Ctrl+Shift+M
  3. Set baud rate to match your code (e.g., 115200)
/* Example sketch with Serial */
#include "Arduino.h"
#include "HardwareSerial.h"

void setup()
{
    pinMode(LED_BUILTIN, OUTPUT);
    Serial_begin(115200);
    Serial_println("Hello from Arduino_dsPIC33CK!");
}

void loop()
{
    int adc = analogRead(A0);
    Serial_print("ADC: ");
    Serial_println_int(adc, DEC);
    delay(500);
}
Note: The Serial Monitor COM port is for your USB-UART adapter (connected to RB4/RB5), NOT the PICkit 4. You may need to select a different port for monitoring vs. programming.

Troubleshooting Arduino IDE Issues

ProblemSolution
Board not visible in Tools menu Run install_arduino_ide.bat again. Restart Arduino IDE completely (close all windows).
"xc16-gcc: No such file or directory" Edit platform.local.txt — set correct path to your XC16 bin folder.
"error: expected ';' before..." (C++ syntax error) You're using C++ syntax. Remove: classes, templates, String, new/delete. Use C-style.
"undefined reference to _setup" Your sketch must have void setup() and void loop() functions.
Upload fails: "ipecmd not found" Edit platform.local.txt — set correct MPLAB X path for tools.pickit4.path
Upload fails: "Target not found" Check PICkit4 connection. Ensure MCLR, VDD, GND, PGD, PGC wired correctly.
"variable declared in for loop" error Declare loop variable before the for: int i; for(i=0;...) instead of for(int i=0;...)
Tip: If you get stuck, you can always fall back to MPLAB X IDE which has full native support for XC16 and dsPIC33CK. The Arduino IDE integration is a convenience layer — MPLAB X gives you the debugger, breakpoints, and register views.

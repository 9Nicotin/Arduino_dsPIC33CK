4.1 Test #1: Blink (Digital Output)

This is the "Hello World" of embedded systems. If this works, your entire toolchain is correctly set up.

What You Need

  • dsPIC33CK32MP102 board with power supply (3.3V)
  • LED (any color) + 330 ohm resistor
  • PICkit 4 or SNAP programmer

Wiring


    dsPIC33CK Pin 2 (RA0) ---[330R]---[LED+]---[LED-]--- GND

    Where:
    - [330R] = 330 ohm resistor (limits current to ~10mA)
    - [LED+] = LED anode (longer leg)
    - [LED-] = LED cathode (shorter leg, flat side)

Sketch Code

Create a file called sketch.c in your MPLAB X project:

/*
 * Test 1: Blink
 * Expected: LED on RA0 blinks ON for 1 sec, OFF for 1 sec
 */
#include "Arduino.h"

void setup()
{
    pinMode(LED_BUILTIN, OUTPUT);  // D0 = RA0 = Pin 2
}

void loop()
{
    digitalWrite(LED_BUILTIN, HIGH);  // LED ON
    delay(1000);                      // Wait 1 second
    digitalWrite(LED_BUILTIN, LOW);   // LED OFF
    delay(1000);                      // Wait 1 second
}

Step-by-Step Testing Procedure

1Build the Project

  1. In MPLAB X, click Production → Build Project (or press F11)
  2. Watch the Output window at the bottom
  3. Wait for: BUILD SUCCESSFUL
Expected: BUILD SUCCESSFUL (total time: x seconds)
If it fails: Check that all core files are added to the project and include paths are set correctly. See Part 5 for common errors.

2Connect the Programmer

  1. Connect PICkit 4 to your PC via USB
  2. Connect the 5-pin ICSP header:
    • Pin 1: MCLR
    • Pin 2: VDD (3.3V)
    • Pin 3: VSS (GND)
    • Pin 4: PGD1
    • Pin 5: PGC1
  3. Ensure the triangle arrow on PICkit aligns with Pin 1

3Program the Device

  1. Click Production → Make and Program Device Main Project
  2. Or click the green "down arrow" icon in the toolbar
  3. Wait for programming to complete
Expected Output:
Connecting to PICkit 4...
Device ID Verified
Programming...
Programming/Verify complete

4Observe the Result

PASS: LED blinks ON for 1 second, OFF for 1 second, continuously repeating.
FAIL - LED stays OFF:
  • Check LED polarity (flip it around)
  • Check resistor value (too high = dim LED)
  • Verify wiring to correct pin (RA0 = physical pin 2)
  • Measure voltage on RA0 with multimeter (should toggle 0V/3.3V)
FAIL - LED stays ON:
  • Code may be stuck in initialization — check config bits
  • Watchdog timer may be resetting — verify FWDTEN = OFF

4.2 Test #2: Serial Output (UART)

Tests the UART communication. You'll see text output on your PC's serial monitor.

What You Need

  • USB-to-UART adapter (3.3V logic: FTDI, CP2102, or CH340)
  • 3 jumper wires
  • Serial terminal software (PuTTY, Tera Term, or Arduino Serial Monitor)

Wiring


    dsPIC33CK                    USB-Serial Adapter
    +---------+                  +--------+
    | RB5 (14)| ----TX------RX--| RX     |
    | RB4 (11)| ----RX------TX--| TX     |
    | GND (8) | ----GND----GND--| GND    |
    +---------+                  +--------+
                                     |
                                  [USB to PC]

    REMEMBER: Cross the wires! TX→RX, RX→TX

Sketch Code

/*
 * Test 2: Serial Output
 * Expected: "Hello from Arduino_dsPIC33CK!" printed every second
 */
#include "Arduino.h"
#include "HardwareSerial.h"

unsigned long count = 0;

void setup()
{
    pinMode(LED_BUILTIN, OUTPUT);
    Serial_begin(9600);  // 9600 baud, 8N1
    delay(100);          // Wait for UART to stabilize
    Serial_println("=== Arduino_dsPIC33CK Started ===");
    Serial_println("Serial communication test");
}

void loop()
{
    count++;
    Serial_print("Loop count: ");
    Serial_println_int(count, DEC);

    digitalWrite(LED_BUILTIN, !digitalRead(LED_BUILTIN));  // Toggle LED
    delay(1000);
}

Testing Procedure

1Open Serial Terminal on PC

  1. Open PuTTY (or Tera Term / Arduino IDE Serial Monitor)
  2. Select "Serial" connection type
  3. Set COM port (check Device Manager for the USB-Serial adapter port)
  4. Set baud rate: 9600
  5. Data bits: 8, Stop bits: 1, Parity: None, Flow control: None
  6. Click "Open"

2Program and Run

  1. Build and program the device (same as Test #1)
  2. After programming, the device resets and starts running
  3. Watch the serial terminal window
Expected output in terminal:
=== Arduino_dsPIC33CK Started ===
Serial communication test
Loop count: 1
Loop count: 2
Loop count: 3
...
FAIL - No output / garbled text:
  • Check baud rate matches (9600 in code AND terminal)
  • Check TX/RX are crossed correctly
  • Check adapter is 3.3V (not 5V!)
  • Check GND is connected between adapter and board
  • Try swapping TX and RX wires

4.3 Test #3: Serial Echo (UART Input + Output)

Tests that you can SEND data TO the dsPIC and receive responses back.

Sketch Code

/*
 * Test 3: Serial Echo
 * Expected: Type a character in terminal, it echoes back with info
 */
#include "Arduino.h"
#include "HardwareSerial.h"

void setup()
{
    pinMode(LED_BUILTIN, OUTPUT);
    Serial_begin(115200);
    Serial_println("=== Echo Test ===");
    Serial_println("Type characters - they will be echoed back.");
}

void loop()
{
    if (Serial_available() > 0) {
        int c = Serial_read();

        // Echo the character
        Serial_print("Received: '");
        Serial_write((uint8_t)c);
        Serial_print("' (0x");
        Serial_print_int(c, HEX);
        Serial_println(")");

        // Blink LED on each received character
        digitalWrite(LED_BUILTIN, HIGH);
        delay(50);
        digitalWrite(LED_BUILTIN, LOW);
    }
}

How to Test

  1. Open serial terminal at 115200 baud
  2. Program the device
  3. Type any character (e.g., press 'A' key)
Expected:
You type: A
Terminal shows: Received: 'A' (0x41)
LED blinks briefly.

4.4 Test #4: Analog Read (ADC)

Tests the analog-to-digital converter by reading a potentiometer.

What You Need

  • 10K potentiometer (any value 1K-100K works)
  • Serial connection (same as Test #2)

Wiring


         3.3V
          |
     +----+----+
     |  [POT]  |   (10K potentiometer)
     +----+----+
          |
          +---------- RB0 (D5/A0, physical pin 4)
          |
     +----+----+
     |  [POT]  |
     +----+----+
          |
         GND

Sketch Code

/*
 * Test 4: Analog Read
 * Expected: ADC value changes 0-1023 as you turn the potentiometer
 */
#include "Arduino.h"
#include "HardwareSerial.h"

void setup()
{
    Serial_begin(115200);
    Serial_println("=== Analog Read Test ===");
    Serial_println("Turn the potentiometer connected to A0 (RB0)");
    Serial_println("ADC range: 0 (0V) to 1023 (3.3V)");
    Serial_println("");
}

void loop()
{
    int value = analogRead(A0);   // Read AN0 (RB0, pin 4)

    // Calculate voltage
    // voltage = value * 3.3 / 1023
    long voltage_mv = (long)value * 3300L / 1023L;

    Serial_print("ADC: ");
    Serial_print_int(value, DEC);
    Serial_print("  Voltage: ");
    Serial_print_int(voltage_mv / 1000, DEC);
    Serial_print(".");
    if ((voltage_mv % 1000) < 100) Serial_print("0");
    if ((voltage_mv % 1000) < 10) Serial_print("0");
    Serial_print_int(voltage_mv % 1000, DEC);
    Serial_println(" V");

    delay(250);
}

How to Test

  1. Wire the potentiometer as shown above
  2. Open serial terminal at 115200 baud
  3. Program and run
  4. Slowly turn the potentiometer from one end to the other
Expected:
ADC: 0 Voltage: 0.000 V (fully CCW)
ADC: 512 Voltage: 1.650 V (middle)
ADC: 1023 Voltage: 3.300 V (fully CW)
FAIL - Always reads 0:
  • Check ANSELB bit is set for RB0 (analogRead does this automatically)
  • Check wiring — is pin 4 connected to pot wiper?
  • Measure voltage on pin 4 with multimeter
FAIL - Always reads 1023:
  • Check that GND leg of potentiometer is actually connected to GND
  • Pin may be floating — verify connections

4.5 Test #5: PWM Output (analogWrite)

Tests pulse-width modulation for LED dimming.

What You Need

  • LED + 330 ohm resistor connected to D5 (RB0, pin 4)
  • Serial connection (optional, for monitoring)

Sketch Code

/*
 * Test 5: PWM LED Fade
 * Expected: LED on D5 gradually brightens then dims, repeating
 */
#include "Arduino.h"
#include "HardwareSerial.h"

void setup()
{
    Serial_begin(115200);
    Serial_println("=== PWM Fade Test ===");
    Serial_println("LED on D5 (RB0) should fade in and out");
}

void loop()
{
    int brightness;

    // Fade in
    for (brightness = 0; brightness <= 255; brightness += 5) {
        analogWrite(5, brightness);  // D5 = RB0, SCCP1 PWM
        delay(30);
    }

    Serial_println("Brightness: MAX");

    // Fade out
    for (brightness = 255; brightness >= 0; brightness -= 5) {
        analogWrite(5, brightness);
        delay(30);
    }

    Serial_println("Brightness: MIN");
    delay(500);
}

How to Test

  1. Connect LED to D5 (RB0, physical pin 4) through 330 ohm resistor
  2. Program and run
  3. Watch the LED
Expected: LED smoothly fades from OFF to full brightness, then back to OFF, repeating every ~3 seconds.
FAIL - LED just turns on/off (no fading):
  • PWM frequency may be wrong — check SCCP configuration
  • PPS may not be mapping correctly — verify RP32 assignment

4.6 Test #6: Timing Functions (millis)

Tests that the timing system works correctly without using delay().

Sketch Code

/*
 * Test 6: Millis-based timing (non-blocking blink)
 * Expected: LED toggles every 500ms, serial prints every 2 seconds
 *           Both happen independently (not blocking each other)
 */
#include "Arduino.h"
#include "HardwareSerial.h"

unsigned long previousLedMillis = 0;
unsigned long previousPrintMillis = 0;
int ledState = LOW;
unsigned long loopCount = 0;

void setup()
{
    pinMode(LED_BUILTIN, OUTPUT);
    Serial_begin(115200);
    Serial_println("=== Millis Timing Test ===");
    Serial_println("LED toggles every 500ms");
    Serial_println("Serial prints every 2000ms");
    Serial_println("Loop counter shows non-blocking operation");
}

void loop()
{
    unsigned long currentMillis = millis();
    loopCount++;

    // Task 1: Toggle LED every 500ms
    if (currentMillis - previousLedMillis >= 500) {
        previousLedMillis = currentMillis;
        ledState = !ledState;
        digitalWrite(LED_BUILTIN, ledState);
    }

    // Task 2: Print status every 2000ms
    if (currentMillis - previousPrintMillis >= 2000) {
        previousPrintMillis = currentMillis;

        Serial_print("Time: ");
        Serial_print_int(currentMillis / 1000, DEC);
        Serial_print("s  Loops: ");
        Serial_println_int(loopCount, DEC);
        loopCount = 0;
    }
}

How to Test

  1. Program and run with serial terminal open (115200 baud)
  2. Observe: LED should blink at 500ms rate (2 Hz)
  3. Observe: Serial prints every 2 seconds
  4. The loop count shows how many times loop() executed in 2 seconds
Expected:
Time: 2s Loops: 158430
Time: 4s Loops: 158425
Time: 6s Loops: 158428
(High loop count proves non-blocking operation)
FAIL - millis() always returns 0:
  • Timer1 interrupt may not be configured
  • Check that IEC0bits.T1IE = 1 in wiring.c
  • Check PR1 calculation matches your FCY

4.7 Test #7: Button Input (digitalRead + INPUT_PULLUP)

What You Need

  • Push button (momentary)
  • Wire from button to D2 (RA2, pin 9)
  • Wire from button other leg to GND

Wiring


    dsPIC33CK Pin 9 (RA2/D2) ----+----[BUTTON]---- GND
                                  |
                            (internal pull-up
                             enabled by code)

    When button is NOT pressed: D2 reads HIGH (pull-up to 3.3V)
    When button IS pressed: D2 reads LOW (connected to GND)

Sketch Code

/*
 * Test 7: Button Input
 * Expected: LED turns ON when button pressed, OFF when released
 *           Serial shows state changes
 */
#include "Arduino.h"
#include "HardwareSerial.h"

#define BUTTON_PIN 2   // D2 = RA2
int lastState = HIGH;

void setup()
{
    pinMode(LED_BUILTIN, OUTPUT);
    pinMode(BUTTON_PIN, INPUT_PULLUP);  // Internal pull-up resistor
    Serial_begin(115200);
    Serial_println("=== Button Test ===");
    Serial_println("Press button on D2 to toggle LED");
}

void loop()
{
    int buttonState = digitalRead(BUTTON_PIN);

    if (buttonState != lastState) {
        lastState = buttonState;

        if (buttonState == LOW) {
            Serial_println("Button PRESSED");
            digitalWrite(LED_BUILTIN, HIGH);
        } else {
            Serial_println("Button RELEASED");
            digitalWrite(LED_BUILTIN, LOW);
        }
        delay(50);  // Simple debounce
    }
}
Expected: Press button → LED ON + "Button PRESSED" on serial. Release → LED OFF + "Button RELEASED".

4.8 Test #8: Complete Integration Test

This sketch tests ALL functions together. If this works, your Arduino_dsPIC33CK platform is fully functional.

What You Need

  • LED on D0 (RA0) — for blink indicator
  • LED on D5 (RB0) — for PWM fade
  • Potentiometer on A1 (D6/RB1)
  • Button on D2 (RA2) to GND
  • Serial connection (115200 baud)

Sketch Code

/*
 * Test 8: Full Integration Test
 * Tests: GPIO, ADC, PWM, UART, Timing, Input
 */
#include "Arduino.h"
#include "HardwareSerial.h"

#define BUTTON_PIN    2    // D2 = RA2
#define PWM_PIN       5    // D5 = RB0 (SCCP1)
#define ANALOG_PIN    A1   // D6 = RB1

unsigned long lastPrintTime = 0;
int mode = 0;  // 0=auto fade, 1=pot controls brightness

void setup()
{
    pinMode(LED_BUILTIN, OUTPUT);
    pinMode(BUTTON_PIN, INPUT_PULLUP);

    Serial_begin(115200);
    delay(100);
    Serial_println("====================================");
    Serial_println("  Arduino_dsPIC33CK Integration Test");
    Serial_println("====================================");
    Serial_println("");
    Serial_println("Functions tested:");
    Serial_println("  [OK] pinMode / digitalWrite / digitalRead");
    Serial_println("  [OK] Serial_begin / print / println");
    Serial_println("  [..] analogRead (potentiometer on A1)");
    Serial_println("  [..] analogWrite/PWM (LED on D5)");
    Serial_println("  [..] millis() timing");
    Serial_println("  [..] Button input (D2)");
    Serial_println("");
    Serial_println("Press button to toggle mode:");
    Serial_println("  Mode 0: Auto LED fade");
    Serial_println("  Mode 1: Pot controls LED brightness");
    Serial_println("");
}

void loop()
{
    static int lastButton = HIGH;
    static int brightness = 0;
    static int fadeDir = 5;

    // Check button for mode toggle
    int btn = digitalRead(BUTTON_PIN);
    if (btn == LOW && lastButton == HIGH) {
        mode = !mode;
        Serial_print(">> Mode changed to: ");
        Serial_println_int(mode, DEC);
        delay(200);  // Debounce
    }
    lastButton = btn;

    // Mode 0: Auto fade
    if (mode == 0) {
        brightness += fadeDir;
        if (brightness >= 255) { brightness = 255; fadeDir = -5; }
        if (brightness <= 0)   { brightness = 0;   fadeDir = 5;  }
        analogWrite(PWM_PIN, brightness);
    }
    // Mode 1: Pot controls brightness
    else {
        int potValue = analogRead(ANALOG_PIN);
        brightness = map(potValue, 0, 1023, 0, 255);
        analogWrite(PWM_PIN, brightness);
    }

    // Toggle status LED every 500ms
    static unsigned long lastLedToggle = 0;
    if (millis() - lastLedToggle >= 500) {
        lastLedToggle = millis();
        digitalWrite(LED_BUILTIN, !digitalRead(LED_BUILTIN));
    }

    // Print status every 1 second
    if (millis() - lastPrintTime >= 1000) {
        lastPrintTime = millis();

        int pot = analogRead(ANALOG_PIN);
        Serial_print("[");
        Serial_print_int(millis() / 1000, DEC);
        Serial_print("s] Mode:");
        Serial_print_int(mode, DEC);
        Serial_print(" ADC:");
        Serial_print_int(pot, DEC);
        Serial_print(" PWM:");
        Serial_print_int(brightness, DEC);
        Serial_print(" Btn:");
        Serial_println(btn == LOW ? "PRESS" : "---");
    }

    delay(20);  // ~50 Hz update rate
}

Expected Results

ALL PASS checklist:
  • Status LED (D0) blinks steadily at 1 Hz
  • PWM LED (D5) fades in and out smoothly (mode 0)
  • Press button → mode changes, serial confirms
  • Turn pot → PWM LED brightness follows (mode 1)
  • Serial prints status every 1 second with correct values
  • Timer (seconds counter) increments accurately

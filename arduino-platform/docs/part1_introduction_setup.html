Arduino_dsPIC33CK User Guide

Part 1: Introduction & Setup

Installing? Use the Boards Manager — no scripts, no path editing.

In Arduino IDE open File → Preferences → Additional Boards Manager URLs and add:

https://github.com/9Nicotin/Arduino_dsPIC33CK/releases/latest/download/package_microchip_dspic33ck_index.json

Then Tools → Board → Boards Manager, search for dsPIC33CK, and click Install. You still need the XC-DSC compiler v4.00+, plus MPLAB X if you upload with a PICkit 4 / SNAP / nEDBG: their licences forbid redistribution, so they cannot ship inside the platform and are located automatically when a build or upload runs. The Device Family Packs are redistributable and are installed for you.

Anything below that uses install_arduino_ide.bat or platform.local.txt is the developer path — it installs an edited working copy of this repo. A normal install needs neither. Windows only.

1.1 What is Arduino_dsPIC33CK?

Arduino_dsPIC33CK is a custom Arduino-compatible platform that allows you to program Microchip's dsPIC33CK32MP102 digital signal controller using the familiar Arduino programming style.

Instead of writing complex register-level code like this:

// Traditional dsPIC33CK code (complex)
TRISAbits.TRISA0 = 0;      // Set RA0 as output
LATAbits.LATA0 = 1;        // Set RA0 high
T1CONbits.TON = 1;         // Start timer
// ... many more register manipulations

You can write simple Arduino-style code:

// Arduino_dsPIC33CK code (simple)
pinMode(LED_BUILTIN, OUTPUT);
digitalWrite(LED_BUILTIN, HIGH);
delay(1000);

How It Works (Architecture)


  +---------------------------+
  |   Your Arduino Sketch     |   <-- You write this (setup/loop)
  |   (Blink.ino)             |
  +---------------------------+
             |
             v
  +---------------------------+
  |   Arduino Core API        |   <-- Arduino_dsPIC33CK provides this
  |   (Arduino.h)             |
  |   digitalWrite()          |
  |   analogRead()            |
  |   millis()                |
  |   Serial_print()          |
  +---------------------------+
             |
             v
  +---------------------------+
  |   dsPIC33CK Hardware      |   <-- Registers, peripherals
  |   Abstraction Layer       |
  |   (variant.c, pin_map)    |
  +---------------------------+
             |
             v
  +---------------------------+
  |   XC-DSC Compiler v4.00+  |   <-- Compiles to dsPIC machine code
  +---------------------------+
             |
             v
  +---------------------------+
  |   dsPIC33CK32MP102 MCU    |   <-- Physical hardware
  +---------------------------+

dsPIC33CK-MP Device Family Pack YES Install via MPLAB X "Packs" tab

IMPORTANT: 3.3V ONLY!
The dsPIC33CK32MP102 operates at 3.3V. Do NOT connect 5V signals to any pin. If using a USB-Serial adapter, ensure it supports 3.3V logic levels.

1.3 Installation Steps

1Install the XC-DSC Compiler

  1. Download XC-DSC v4.00 or newer from microchip.com/xc-dsc
  2. Run the installer (accept defaults)
  3. Default path: C:\Program Files\Microchip\xc-dsc\v4.00\
  4. No PATH change needed — the platform locates any v* directory under C:\Program Files\Microchip\xc-dsc\ when a build runs, newest first

Verify installation — open Command Prompt and type:

"C:\Program Files\Microchip\xc-dsc\v4.00\bin\xc-dsc-gcc.exe" --version

Expected output: xc-dsc-gcc (Microchip XC-DSC ... v4.00) .... Use the full path: XC-DSC is not added to PATH, and the platform does not need it to be.

2Install MPLAB X IDE

  1. Download from microchip.com/mplab
  2. Install with default options
  3. Open MPLAB X → Tools → Packs
  4. Search for dsPIC33CK-MP_DFP and install it

3Set Up the Arduino_dsPIC33CK Platform

Installing from the Boards Manager URL (see the banner at the top) puts the platform under %LOCALAPPDATA%\Arduino15\packages\microchip\. If you cloned the repo to work on the platform itself, its source lives at:

<your-clone>\arduino-platform\

Folder contents:

arduino-platform/
├── microchip/dspic33ck/
│   ├── boards.txt            (board config)
│   ├── platform.txt          (compiler config)
│   ├── cores/arduino/        (Arduino API source files)
│   ├── variants/dspic33ck32mp102/  (pin mapping)
│   ├── bootloaders/          (serial bootloader, MC005)
│   ├── tools/serial_upload.py  (serial upload script)
│   └── libraries/Arduino_dsPIC33CK/examples/  (Blink, AnalogRead, ...)
├── package_...index.json     (board manager)
└── README.md

4Create an MPLAB X Project Using This Platform

  1. Open MPLAB X → File → New Project
  2. Select Microchip Embedded → Standalone Project
  3. Device: dsPIC33CK32MP102
  4. Tool: PICkit 4 (or your programmer)
  5. Compiler: XC-DSC (v4.00 or newer)
  6. Project Name: Arduino_dsPIC33CK_Test

5Add Arduino Core Files to Project

In MPLAB X, right-click "Source Files" → Add Existing Items From Folders:

Add these source files (.c):

arduino-platform/microchip/dspic33ck/cores/arduino/main.c
arduino-platform/microchip/dspic33ck/cores/arduino/system_config.c
arduino-platform/microchip/dspic33ck/cores/arduino/wiring.c
arduino-platform/microchip/dspic33ck/cores/arduino/wiring_digital.c
arduino-platform/microchip/dspic33ck/cores/arduino/wiring_analog.c
arduino-platform/microchip/dspic33ck/cores/arduino/wiring_shift.c
arduino-platform/microchip/dspic33ck/cores/arduino/HardwareSerial.c
arduino-platform/microchip/dspic33ck/variants/dspic33ck32mp102/variant.c

Add these header files (.h):

arduino-platform/microchip/dspic33ck/cores/arduino/Arduino.h
arduino-platform/microchip/dspic33ck/cores/arduino/system_config.h
arduino-platform/microchip/dspic33ck/cores/arduino/HardwareSerial.h
arduino-platform/microchip/dspic33ck/variants/dspic33ck32mp102/pins_arduino.h

6Configure Include Paths

Right-click Project → Properties → XC-DSC (Global Options) → xc-dsc-gcc → Preprocessing and messages

Add Include directories:

../arduino-platform/microchip/dspic33ck/cores/arduino
../arduino-platform/microchip/dspic33ck/variants/dspic33ck32mp102

Add Preprocessor Macros (in the same properties page):

F_CPU=8000000UL
FCY=4000000UL
ARDUINO_DSPIC33CK32MP102

7Write Your First Sketch

Create a new file called sketch.c in your project's Source Files:

/* sketch.c - Your Arduino sketch */
#include "Arduino.h"

void setup()
{
    pinMode(LED_BUILTIN, OUTPUT);  // D0 = RA0
}

void loop()
{
    digitalWrite(LED_BUILTIN, HIGH);
    delay(1000);
    digitalWrite(LED_BUILTIN, LOW);
    delay(1000);
}
Note: Do NOT include your own main() function. The Arduino core's main.c already handles calling setup() once and loop() repeatedly.

8Build & Program

  1. Click the Build button (hammer icon) or press F11
  2. Fix any errors (see Troubleshooting in Part 5)
  3. Connect PICkit 4 to the board ICSP header
  4. Click Make and Program Device (down-arrow icon)
  5. Watch the LED blink!
